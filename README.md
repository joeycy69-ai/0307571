# 作業 05：向量相似度實驗

## 功能說明

使用 OpenAI Embeddings API 進行向量相似度實驗，驗證文本相似度計算的正確性。

## 文件說明

### `lib/embeddings.js`
- **getEmbedding(text)**: 使用 Embeddings API 將文本轉換為向量表示
- **cosineSimilarity(vec1, vec2)**: 計算兩個向量之間的餘弦相似度
- **calculateSimilarities(texts)**: 計算文本列表中兩兩之間的相似度

### `similarity-test.js`
相似度測試程序，包含 3 組測試用例：

#### 第 1 組：意思相近的句子
```
1. 我喜歡貓
2. 貓咪很可愛
3. 我養了一隻貓
```

相似度矩陣：
| | 句1 | 句2 | 句3 |
|---|---|---|---|
| **句1** | 1.0000 | 0.6985 | 0.6746 |
| **句2** | 0.6985 | 1.0000 | 0.5534 |
| **句3** | 0.6746 | 0.5534 | 1.0000 |

平均相似度：**0.6422**

#### 第 2 組：意思不同的句子
```
1. 今天天氣很好
2. 我要去買菜
3. 電腦壞了
```

相似度矩陣：
| | 句1 | 句2 | 句3 |
|---|---|---|---|
| **句1** | 1.0000 | 0.2873 | 0.2356 |
| **句2** | 0.2873 | 1.0000 | 0.2414 |
| **句3** | 0.2356 | 0.2414 | 1.0000 |

平均相似度：**0.2548**

#### 第 3 組：自定義測試案例（程式設計相關）
```
1. JavaScript 是一種程式語言
2. JavaScript 可以用來開發網頁應用
3. 我喜歡用 JavaScript 編寫程式
```

相似度矩陣：
| | 句1 | 句2 | 句3 |
|---|---|---|---|
| **句1** | 1.0000 | 0.6733 | 0.6584 |
| **句2** | 0.6733 | 1.0000 | 0.6333 |
| **句3** | 0.6584 | 0.6333 | 1.0000 |

平均相似度：**0.6550**

## 實驗結果分析

✅ **第 1 組與第 2 組的差異符合預期**
- 相近句子的平均相似度（0.6422）明顯高於不同句子的平均相似度（0.2548）
- 相似度差異度：**0.3874**（2.5 倍之多）
- 驗證了 Embeddings API 能夠有效區分語義相似與不同的文本
